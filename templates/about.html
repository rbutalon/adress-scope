AddressScope is a Flask-powered dashboard for checking the public IPv4 and IPv6 addresses visible to the internet, along with location and network metadata supplied by ipapi.co.

Separate family checksIPv4 and IPv6 are requested independently and validated with Python's ipaddress module.
Backend-only API accessThe browser talks only to the local Flask API. External service credentials and network handling stay server-side.
Honest availabilityMissing connectivity or fields are shown as unavailable instead of being replaced with example data.
